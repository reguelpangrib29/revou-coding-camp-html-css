# revou-coding-camp-html-css

Kumpulan latihan HTML & CSS dari **RevoU Coding Camp**. Repo ini berisi file-file latihan dasar yang dibuat selama mengikuti sesi belajar, mulai dari struktur HTML, teks, tabel, form, gambar, hingga list dengan styling modern menggunakan Tailwind CSS v4.

---

## Daftar File

| File | Deskripsi |
|---|---|
| `index.html` | Latihan dasar HTML — heading (h1–h6), paragraf, bold, italic, subscript, superscript, `<hr>`, dan `<br>` |
| `list.html` | Latihan unordered list dengan tampilan glassmorphism + gradient background menggunakan Tailwind CSS v4 |
| `tabel.html` | Latihan membuat tabel HTML dengan header (`<th>`) dan baris data (`<td>`) |
| `form.html` | Latihan elemen form — input text, checkbox, radio, password, textarea, select/option, dan button |
| `image.html` | Latihan penggunaan tag `<img>` untuk menampilkan gambar |

---

## Teknologi

- **HTML5** — struktur dan semantik dasar
- **Tailwind CSS v4** — utility-first CSS framework (via CDN, dipakai di `list.html`)

---

## Cara Menjalankan

Tidak perlu build tool atau server. Cukup buka file `.html` langsung di browser:

```
Klik dua kali file .html  →  buka di browser
```

Atau gunakan ekstensi **Live Server** di VS Code untuk auto-reload saat editing.
